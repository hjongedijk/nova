NOVA controleert automatisch op nieuwe versies. Jij kiest wanneer de update wordt geïnstalleerd.

Windows vraagt toestemming om de poort van NOVA in de firewall te openen, zodat NOVA deze pc kan bereiken.

Plak deze code in NOVA → Instellingen → Windows-pc. De code is de enige koppeling tussen NOVA en deze pc: bewaar hem als een wachtwoord.

NOVA op deze pc

Met de koppelcode heeft NOVA volledige toegang tot deze pc: meekijken, muis en toetsenbord, browser en programma's, zonder verdere instellingen. Ctrl+Alt+Shift+K is de noodstop: die pauzeert NOVA direct. Hervatten kan alleen via het systeemvak.

Oude agent vervangen

Importeren herstart NOVA als de poort verandert. Uitschakelen stopt de oude PowerShell-agent in deze map, verwijdert taken NOVAAgent en JarvisAgent en sluit NOVA Desk. Bestanden blijven bewaard.

Instellingen: %LOCALAPPDATA%\NOVA\config.json. Sluiten laat NOVA actief bij de klok.
