# NOVA v0.1.56

NOVA can hold real spoken conversations. Call extension 700 from a Linphone toestel (or have NOVA call you) and she listens, answers sentence by sentence while she is still writing, and lets you interrupt her. Phone conversations use read-only tools only and anything that needs a screen confirmation is refused. Conversations are off by default: switch them on in Settings → Gesprekken, together with Telefonie. Speech recognition goes through OmniRoute and needs a free transcription model inside the verified key scope (see [the guide](../conversations.md)).

Linphone accounts work through a SIP trunk: add a second Linphone account for NOVA as the trunk and your own address as a contact (Settings → Telefonie → Contacten). NOVA can then call you by name, optionally talk with you, and only contacts you allow can start a conversation by calling her.

3D modelling and slicing now run on your Windows PC through the agent (`2026-10-16.2`, off unless `fabrication.enabled` is set in `agent.json`), with the server's sandbox container as fallback. Install OpenSCAD and Bambu Studio on the PC and set the slicer command line you verified; see the fabrication slicing guide (removed in v0.1.59). Update the agent from NOVA's download to get the new endpoints.

Update NOVA and its matching gateway image together using the production Compose file. No data migration is needed.
