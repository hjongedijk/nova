# NOVA v0.1.85

Replaces the previous portrait with a different human model, derived from VTubeMe Sky under CC BY 4.0. The portrait keeps the source face, integrated hairstyle, textured eyeballs, eyelashes, facial expressions and normal maps. An offline extraction removes unused body and clothing assets, reducing the bundled model from approximately 20 MB to 2.5 MB. Attribution is included in the served credits and asset documentation.

The holographic treatment now uses finer surface connections, light nodes and contour lines, restrained optical glow, and an atmospheric corona. The source rig receives a head orientation correction. Original eye textures replace the previous coordinate-based iris reconstruction. Shared face/orb selection and the existing speech player remain in place; mouth animation still follows amplitude rather than phoneme timings.

Validation covers deterministic asset extraction, type checks, lint, web tests, production build, real browser renders, eye movement, blink and expression controls, speech playback without the original orb, and renderer cleanup. Production rollout requires successful GitHub CI and Release workflows and includes a backup and browser checks.
