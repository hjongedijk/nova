# NOVA v0.1.99

Adds **Gestalte**, an optional presence that grows out of the orb. The orb stays the default.

- **Procedural, original figure.** A head and shoulders built from a distance field of ellipsoids and capsules, cut into horizontal contour rings. No image, texture or borrowed look, so nothing warps or shimmers when it turns: head turns are real 3D rotations.
- **Grows from the orb.** Each ring starts as one of the orb's latitude lines and slides into its body slice, head first, then the shoulders; dissolving runs the same path back and can be interrupted midway.
- **Alive per state.** Rim light and a soft key light, two slits of light for eyes that blink, and a mouth glow and jaw movement driven by the voice level. Ready scans slowly, listening tilts the head, thinking looks up and aside with orbits around the head, executing sweeps fast, and speaking runs the voice ring by ring from the mouth, each in NOVA's state colour. The gaze follows the pointer gently and it breathes when idle.
- **Light enough for a wallpaper.** It uses the existing Canvas 2D loop and builds its geometry only when chosen, adding about 1 ms of script time per frame. Line density scales with the screen. Reduced motion turns off gaze, sway, breathing, blinking and particle flow.
- **Where to choose it.** Instellingen, Windows, "Helper en achtergrond", Gedaante: Gestalte, or Gedaante in the helper settings. One setting covers the website, the wallpaper and the helper.

Validation: svelte-check, web tests (434), lint, Prettier, the production build, the full API suite, and headless renders of every state from 800x600 to 3840x2160. Real GPU frame times and side-panel readability over the figure still need a check on a Windows PC.
