# NOVA v0.1.57

Real spoken conversations can now use a dedicated, tightly restricted OmniRoute key for speech-to-text (for example `groq/whisper-large-v3-turbo`, free tier). NOVA checks in OmniRoute's own records, before every request, that the key allows exactly that model and one connection of its provider, and sends nothing otherwise. Typical latency is about 300 ms for a short sentence. Setup is described in [the conversations guide](../conversations.md).

Asterisk is now part of the main Compose file (profile `telephony`, private `nova` network, no published ports) and ships with releases; Settings → Telefonie no longer reports Asterisk as unreachable while no phone or trunk is configured yet. Adding a provider account in OmniRoute no longer leaves AI blocked when OmniRoute stores the key encrypted.

Dutch call verbs ("bel", "bellen", "telefoneer") now offer the phone tool, so "bel mij en vertel het weer" can work. When every free model has recently failed upstream, NOVA now tries the one due to recover first instead of refusing chat for several minutes.

Update NOVA and its matching gateway image together using the production Compose file. To use Asterisk, copy the shipped `asterisk/` folder next to `docker-compose.yml` and add `telephony` to `COMPOSE_PROFILES`.
