# NOVA v0.1.69

Herstel: de tekstberichten van de autopilot kwamen nooit aan, omdat NOVA de telefooncentrale met de verkeerde HTTP-methode (POST in plaats van PUT) vroeg een bericht te sturen. Berichten van NOVA naar je Linphone werken nu; dit is met een echt testbericht gecontroleerd.

Een blijvend doel dat een model zelf voorstelt vraagt nu om jouw bevestiging. Eerder kon een gewone meningsvraag ("is het slim om mijn servers 's nachts te herstarten?") ongevraagd een doel aanmaken. Zeg je zelf "houd ... in de gaten", dan wordt het doel nog steeds meteen gemaakt.

Werk NOVA en de bijbehorende gateway-image samen bij met het productie-Compose-bestand.
