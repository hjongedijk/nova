# NOVA v0.1.91

Desktop wallpaper enlarges the humanoid and anchors the torso at the bottom, behind the input. A separate background layer extends the original cyan/gold mountain artwork to both screen edges; the procedural grid becomes a subtle secondary layer. The avatar is sized by viewport height and available width instead of a fixed 640px limit. The speaking target follows the enlarged head. Website and compact-helper framing remain unchanged.

Includes the stable continuous-surface renderer from v0.1.90, preserving fine contours during head/torso gestures with mipmap and anisotropic filtering. Combined head-turn angles remain bounded to avoid excessive distortion. Shared appearance preferences, reduced-motion support and speech energy remain intact.

Validation: 438 web tests, Svelte checks, lint, production build and browser checks for independent head/torso movement, reduced motion, full-resolution rendering, cleanup, audio playback and full-viewport wallpaper layout. Composer input is verified while the portrait fills the background; no messages or production settings are written by browser checks.
