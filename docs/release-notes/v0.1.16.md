# NOVA v0.1.16

- Codeweergave crasht niet meer wanneer nog geen sandbox-run bestaat. De API stuurt expliciet JSON `null`; de interface ondersteunt ook de lege antwoorden van oudere servers.
- Serviceworker kloont een response voordat de pagina die leest. Cachefouten veroorzaken geen onbehandelde promise-fout; een nieuwe shell-cache vervangt de oude.
- De meegeleverde MCP-catalogus is leesbaar zonder schrijfrechten te geven. Alleen-lezen configuratie geeft geen HTTP 400 bij het openen van instellingen; beheermogelijkheden blijven beperkt tot lokaal beheerde configuratie.
- MCP-verversen, synchronisatie en afsluiten delen één lifecycle-wachtrij. Gelijktijdige verzoeken overschrijven geen levende verbinding meer en veroorzaken geen achtergebleven worker.
- NOVA-browservoorkeuren gebruiken nieuwe namen en behouden bestaande conversaties, microfoonactivatie, panelen en spraakmeldingen. Oude kopieën blijven beschikbaar voor terugrollen.
- Gratis-modelterugval sluit afgewezen HTTP-responses voordat de volgende poging begint.

Bijwerken: behoud bestaande `.env`, gegevens en Compose-configuratie. Zet `NOVA_VERSION=0.1.16` en voer `docker compose pull nova stack-control mcp-egress && docker compose up -d nova stack-control mcp-egress` uit. Herlaad de browser na de update zodat de nieuwe serviceworker wordt geactiveerd.
