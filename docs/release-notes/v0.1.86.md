# NOVA v0.1.86

Rebuilds the portrait from reference-based artwork: a faceless cyan contour figure, orange energy inside the face, fine neck conduits and a connected shoulder field. The image becomes a bounded colored-particle projection with shallow inferred depth, subtle breathing, pointer parallax and speech-reactive facial energy. This replaces the conventional human model. The original orb remains available through the shared avatar preference.

The previous GLB model, TalkingHead dependency, unused portrait effects and model preparation script are removed. The new artwork is local and requires no avatar service or additional voice. Reduced motion disables autonomous movement and pointer parallax; cleanup releases the renderer and event listeners.

This is an independent visual reconstruction from the supplied reference, not the original APEX source or animation system. The faceless design uses energy reactions instead of eye and mouth rigging.

Validation includes source-color sampling and particle-budget tests, web tests, type checks, lint, production build, real browser rendering at full and compact sizes, live speech playback, shared face/orb selection and resource cleanup.
