# NOVA v0.1.92

Enlarges the desktop humanoid by approximately 32% compared with v0.1.91. Framing keeps the head near the top while the lower chest extends below the composer. Narrow screens use a width constraint so the face stays visible. The speaking target is enlarged to follow the face.

The main website now uses the same full-height portrait framing as wallpaper mode, removing its separate 640px frame. Compact helper framing and original-orb behavior remain unchanged. The stable surface renderer, mountain field, motion and shared appearance preferences are preserved.

Validation: Svelte checks, production build, focused lint and desktop/mobile browser checks for full-viewport framing, shared face/orb switching, no horizontal overflow and usable composer input. Deployment verifies the served website, wallpaper and speech renderer.
