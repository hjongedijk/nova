# v0.1.52

Fix streaming text around private assistant mood headers. Leading whitespace or different header casing could hold visible text until completion. Later short fragments could disappear from streamed text even though the final model response contained them.

Only possible partial headers remain buffered. Complete headers are removed as they arrive; only the initial valid header selects mood. Visible continuation text and the final buffered tail are emitted once. Model budgets, provider routing and tool authorization remain unchanged.

Regression coverage includes text arriving before upstream completion, split and mixed-case headers, ordinary short replies, invalid/embedded/repeated headers and literal less-than signs. Production voice latency and physical audio remain separate acceptance checks.

Validation: 2,529 API tests across150files, API typecheck/build, scoped lint and eight compiled streaming cases pass. Web source is unchanged from the verified0.1.51 build.
