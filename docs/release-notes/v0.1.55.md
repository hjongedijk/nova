# NOVA v0.1.55

NOVA can now run tasks on its own. Autonomous tasks run once, repeatedly or when a Node-RED event arrives, survive restarts, retry read-only steps with backoff, and pause risky steps until you approve them in Settings → Zelfstandige taken. The new "NOVA taak starten" Node-RED block starts event tasks from MQTT or Home Assistant flows. Dangerous actions never run unattended.

A holographic viewer (Three.js) shows real data from Proxmox, Home Assistant, the network and NOVA's own tool activity, and previews 3D models. Ask for it in conversation ("toon mijn Proxmox").

3D design and printing is added: parametric parts are generated in a sandboxed OpenSCAD container, validated, previewed, revised with undo, and sliced. A print only starts after your explicit approval and a fresh confirmation, is sent at most once, and an unknown outcome is never retried. No printer or slicer is linked yet, so printing is unavailable until you set them up (see [the fabrication guide](../fabrication-architecture.md)). The CAD container image `nova-cad:openscad` is built on the Docker host from `deploy/fabrication`.

Desktop view and control, and a built-in Asterisk phone system with Linphone provisioning, are included and **off by default**. Desktop control additionally needs the updated Windows agent with `desktop.enabled` set on the PC; control sessions last at most 15 minutes, show a red bar, and stop at once with the kill-switch hotkey. See [desktop control](../desktop-control.md) and [telephony](../telephony.md).

Update NOVA and its matching gateway image together using the production Compose file. No data migration is needed. Windows agent `2026-10-16.1` is optional and only required for desktop control.
