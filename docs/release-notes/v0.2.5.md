# NOVA v0.2.5

- **Live windows (Jarvis view).** NOVA's work shows up as multiple floating windows open at the same time. They can be dragged, resized, docked, maximized and tiled, and there is a Mission control overview with every window as a tile:
  - **Browser:** a live CDP screencast of the tab NOVA is working in, with address bar, tabs, loading bar, click ripples and typing caret (password fields masked).
  - **Scherm:** the live PC desktop, 2 to 15 fps adaptive, with an overlay of clicks and typed text. A Windows agent older than 0.1.8 falls back to a labelled snapshot refresh.
  - **Terminal:** `termix_run_command` over direct SSH streams its output live into xterm.js, with redaction that also catches secrets split across chunks, exit code, duration and a copy button.
  - **Video:** new `window_open` tool (kinds video, page, image, document). It plays YouTube (nocookie embed), Vimeo or mp4/webm, can find a video from a query via SearXNG videos, and has a floating mode.
  - **Resultaat:** at the end of a browser task the final page opens large, in an iframe when the site can be framed, otherwise as the last frame plus "Openen in nieuw tabblad". Reader view for web_read.
  - **Limits:** the focused window gets full fps and smaller tiles less; a hidden or minimized window pauses. At most 8 live streams, with per-frame and total bandwidth caps; frames that fall behind are dropped instead of queued. The `/api/live` websocket requires the own Origin and Host, and frames never go to the audit log.
- **Aura (new shape, opt-in).** A feminine light figure with natural proportions, flowing hair made of light strands, contour strokes and a smoke backdrop. Moods bloom out from the face, it weaves in at birth, the head follows the pointer and it breathes. The orb stays the default.
- **Fix:** env flags such as `COREPACK_ENABLE_AUTO_PIN=0` no longer make redaction replace every "0" in text.

Use with NOVA for Windows v0.1.8 for live screen and browser video.
