# NOVA v0.1.13

- MCP: containercreatie en verwijdering krijgen een begrensde termijn van 60 seconden. Daardoor veroorzaakt een trage Docker-daemon geen verloren workers na de oude timeout van vijf seconden.
- De broker wacht maximaal 75 seconden op voorbereiding; NOVA wacht maximaal 90 seconden op de eerste geïsoleerde verbinding. Gereedschapsaanroepen behouden hun bestaande tijdslimiet.
- Een workernaam wordt vóór creatie gereserveerd. Bij een onzekere fout wordt alleen die eigen worker herhaaldelijk opgeruimd; capaciteit wordt pas na bevestigde verwijdering vrijgegeven. Netwerkisolatie, beperkte mounts en de niet-rootgebruiker blijven gelden.

Bijwerken: behoud je bestaande `.env`, gegevens, `nodered/` en Compose-configuratie. Zet `NOVA_VERSION=0.1.13` en voer `docker compose pull nova stack-control mcp-egress && docker compose up -d nova stack-control mcp-egress` uit. De bundel van v0.1.12 bevat de benodigde Node-RED-bestanden. Deze patch bevat uitsluitend de MCP-opstartfix.
