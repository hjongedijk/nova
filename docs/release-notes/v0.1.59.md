# NOVA v0.1.59

NOVA can now work on a goal by herself. Say "zoek dit uit en laat het me weten" and she keeps using her tools in the background, within turn, time and daily limits, and tells you when she is done or needs help. Waiting approvals and questions show up in Settings → Zelfstandige taken, and a task interrupted by a restart can be resumed.

New setting "Hoe zelfstandig is NOVA?" (Voorzichtig, Gebalanceerd, Zelfstandig). On Gebalanceerd, routine actions such as lights, music, calendar entries and calls to your saved contacts run without asking. Destructive, shell and settings actions always ask. Text from websites, mail or documents puts NOVA on Voorzichtig for three minutes. NOVA's prompt is also about half the size, which saves free-tier quota.

Answers can now show a small hologram card under the text (weather, CPU/RAM gauges, calendar timeline, status tiles), built only from real tool results. It starts flat and upgrades to 3D when the device allows it.

Settings are reorganised into seven plain-language groups with tabs, shared components and rewritten Telefoon and Gesprekken texts. Old `?section=` links still work.

The chat composer is cleaner: one "+" menu, the microphone next to the input, and the model line is hidden. 3D printing is removed. Phone calls and Linphone chats now remember earlier turns.

Windows agent 2026-10-16.4 adds tray toggles "Bureaublad: meekijken aan/uit" and "Bureaublad: bedienen aan/uit". Update the agent on the PC to use them.

Update NOVA and its matching gateway image together using the production Compose file.
