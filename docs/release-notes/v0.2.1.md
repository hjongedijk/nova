# NOVA v0.2.1

Republishes everything in v0.2.0, whose container image build hung on GitHub and was cancelled after six hours, and adds:

- **Gestalte v3.** The optional figure comes closer to the reference look: clearly wavy dotted lines across the face with a broad warm amber field behind them (no white hotspot while speaking), a thicker and more luminous rim with a wide soft halo and fine sparks drifting upward from the crown, sides and shoulders, dense ridged particle mountains with many orange streaks, finer branching veins from the jaw into the chest, and chest lines that wrap the shoulders and sternum. Each layer is still a single draw call. The orb stays the default.
- **Release pipeline.** Release jobs now time out after 60 minutes instead of GitHub's six-hour default, and the version test no longer fails once the repository reaches the version it uses.

Validation: svelte-check, web tests, lint, Prettier, the production build, the full API suite and a local amd64 image build.
