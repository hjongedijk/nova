# NOVA v0.1.96

NOVA acts on its own more and nags less.

- **Acts instead of asking.** The core prompt now tells NOVA never to ask whether it should look something up or check something; it does it in the same turn. Ambiguous names are resolved with a search first. A reported fault is checked and fixed with tools instead of answered with a suggestion. NOVA is told it can set up its own routines, reminders and watches (`autonomy_create`, `objective_create`, `agent_run`) and does so without being asked. `web_search`, `web_read` and `memory_remember` are offered with every request when there is room, so a lookup or a stated fact no longer depends on a keyword in the message. The `autonomy_create` description no longer claims steps wait for approval.
- **No more proposals for NOVA's own services.** LAN discovery proposed the MQTT broker, Node-RED and Qdrant on the compose network (172.20.0.x) every week, through Linphone too. Discovery now resolves the stack hostnames and never proposes MQTT, Node-RED, Qdrant, OmniRoute or Home Assistant on that subnet. Services on the real LAN are still proposed.
- **Smaller database.** The action log stored full results of background polls: the autopilot read the complete Home Assistant entity list (about 40 KB) every few minutes, about 12 MB a day, and `nova.db` had reached 300 MB. Read-only autopilot polls and empty scans are no longer logged, results larger than 16 KB are stored shortened (shape, `ok`, first 20 items), and migration 2 shrinks existing oversized rows.
- **Backups.** GNU tar exit code 1 (a state file changed while it was read) no longer fails the daily or weekly backup; the archive is still verified. A failing backup now logs its cause on the server (the alert text is unchanged).
- **Autopilot.** The standing-objectives bootstrap retries every six hours while nothing could be set up, instead of giving up after the first start. The daily "today" scan stops polling lists and timers once it has reported. Autopilot and objective sessions no longer fill conversation memory.

Validation: API typecheck, lint, Prettier and the full API suite (3241 tests), with new tests for audit bounding, the compaction migration and own-stack discovery.
