# NOVA v0.1.98

A cleaner desktop helper and a server side that matches the new Windows app.

- **Helper restyle.** The helper uses NOVA's own tokens (navy-black, cyan accent, amber and green), the Sora typeface at 11 to 16 px, and one orb on screen. The overview shows cards for the workspace and lists, unconnected services are grey instead of warning orange, block details have a close button and no longer cover the list, preferences are grouped with real switches and a save button that stays visible, weather shows the temperature large with wind, humidity and an hourly forecast, notifications use a severity dot, and file and choice rows sit inside the chat card. Menus grow from their button with a short ease-out; all motion honours reduced motion, and Windows high-contrast and forced colours are supported. Long, empty, non-Latin and 500-item data no longer overflow sideways.
- **Windows app contract.** A paused PC (409) is reported as paused instead of "access off", the agent's fixed error texts are shown in Dutch, and the native app's shortcut and emergency-stop warnings are explained. `browser_click_confirmed`, `windows_close_app` and `windows_lock` no longer need confirmation, browser clicks no longer force a screen confirmation, and `browser_type` accepts up to 5000 characters like the agent. Use with NOVA for Windows v0.1.5.

Validation: svelte-check, web tests (431), lint, Prettier, the production build, the helper screenshot and layout checks (144 layouts) at 1x and 2x, and the full API suite.
