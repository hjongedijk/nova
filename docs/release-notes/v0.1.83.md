# NOVA v0.1.83

The avatar choice now applies to NOVA's website on desktop and mobile as well as the wallpaper and helper. Choosing **Gezicht** displays the animated face everywhere; **Originele orb** restores the existing orb. The shared setting is labelled **Avatar voor website, wallpaper en helper**.

Validation: Svelte type check, focused lint, web production build and browser checks at desktop and mobile widths, including synchronized switching in both directions. Browser checks block production writes and PC actions.
