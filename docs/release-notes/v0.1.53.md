# v0.1.53

Preserve numeric text fragments from Cloudflare’s OpenAI streaming endpoint. The gateway previously discarded numeric JSON values, so a correct clock reading could become `::` and speech would fail.

NOVA now publishes a matching `nova-omniroute` image based on the same audited upstream 3.8.51 digest. Two guarded build-time changes convert finite numeric content into text and serialize that correction onto the SSE wire. Strings, tools, usage, provider credentials, routing policy and the existing gateway data format remain unchanged.

Eight patch regressions and 17 checks against the real compiled gateway pass, including complete mocked SSE passthrough. An independent review found and verified the necessary wire-serialization correction. NOVA API and frontend source are unchanged from 0.1.52; their latest passing counts are 2,529 and 264 tests.

Update the Compose file before pulling this release: it now uses `ghcr.io/<owner>/nova:omniroute-X.Y.Z` with the same `NOVA_VERSION` as the main image. Preserve the existing `omniroute-data` mount. The gateway tag shares NOVA’s existing public image package and access permissions. Rolling back to a release before 0.1.53 also requires its old Compose file. The upstream digest and package version are fixed; incompatible compiled code stops the image build.

This patch cannot reconstruct whitespace or numeric precision already lost upstream. Physical audio and representative p95 latency remain separate acceptance checks.
