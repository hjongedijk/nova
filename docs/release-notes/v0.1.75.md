# NOVA v0.1.75

De knop **Windows-agent downloaden** staat direct bovenaan **Instellingen → Windows-pc**, naast de verbindingscontrole. Je hoeft geen sectie meer open te klappen. De knop opent de Windows-releases in een nieuw tabblad. De dubbele link onder Helper en achtergrond is verwijderd.

Deze update wijzigt geen gegevensopslag of Windows-agent. Werk de NOVA-image en bijbehorende Compose-assets bij zoals beschreven in [Bijwerken](https://github.com/hjongedijk/nova/blob/v0.1.75/docs/getting-started.md#updating).
