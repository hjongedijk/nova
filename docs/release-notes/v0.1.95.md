# NOVA v0.1.95

Restores the original procedural orb across the website, wallpaper and helper. Removes the rejected humanoid renderer, its image asset and both face selectors. The helper uses the orb directly, without loading a portrait module. Existing sidebar readability improvements remain intact.

Legacy face preferences normalize to the orb in the settings API and client preference loaders. Other preferences, orb shapes, themes, notifications and voice settings are preserved. No database rewrite is required.

Validation covers legacy-preference normalization, Svelte checks, web tests, focused lint, production build and browser checks on website, wallpaper and helper using saved face preferences. The checks block production mutations and confirm the rejected renderer and artwork are not requested.
