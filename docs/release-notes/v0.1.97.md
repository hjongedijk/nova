# NOVA v0.1.97

NOVA learns, repairs and keeps listening on its own.

- **Learns preferences at night.** At 03:05 NOVA reads the day's user-written messages (never tool output, web pages or mail) and stores up to ten durable facts (preferences, habits, people, places) as unconfirmed memories. Secrets and card numbers are filtered, duplicates are skipped, and the model call goes through the verified free route.
- **Repairs instead of only reporting.** A warning or urgent finding from the health or home scan starts a repair run (find the cause, restart or reload what is needed, report what was done), at most once an hour per problem and six times a day. Objective investigations now also fix what they can instead of only reading.
- **Real morning briefing.** The morning ritual starts a short briefing from the calendar, weather and news. Rituals run within a two-hour window, so a missed minute no longer skips the day. Morning briefing, welcome home and calendar reminders are on by default.
- **Self-tuning recovers.** A nudge nobody answered (phone, Linphone and speech cannot be answered) no longer counts against the autopilot; before, tuning only ever got quieter.
- **Local speech-to-text fallback.** A new optional `speaches` service (profile `local-stt`, faster-whisper on CPU) transcribes when the OmniRoute route fails. `NOVA_LOCAL_STT_URL=off` turns the fallback off.
- **Dutch Piper fallback voice.** When the Microsoft voice fails, a Dutch reply is spoken by the local Piper voice `nl_NL-pim-medium` (English replies keep the Jarvis voice). The default voice is now Maarten (`nl-NL-MaartenNeural`).

Validation: API typecheck, lint, Prettier, the full API suite, web tests and svelte-check; Piper with the Dutch voice and speaches transcription were checked against real containers.
