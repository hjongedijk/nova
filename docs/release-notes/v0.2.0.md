# NOVA v0.2.0

NOVA works on its own with far fewer limits, holds a real conversation, shows what it is doing, learns new skills and keeps outsiders out.

- **Fewer limits.** Home Assistant allows every entity unless the owner set an allowlist; program names and paths of any form open on the PC ("Plex", spaces, full paths); autonomous task steps run without waiting for approval; agent runs get up to 30 turns, 60 minutes, 4 at once and 500 turns a day; desktop sessions allow 300 actions, 200 looks and 4,000 typed characters, start by themselves on the first action, and a second start extends the running one; browser clicks are never refused; up to 16 tool rounds per answer (cap 32) and 32 tools per request; server commands up to 8,000 characters; objectives can watch with any read-only tool. On a robot check NOVA switches to DuckDuckGo or Bing.
- **Real conversations.** Voice turns are short, build on what was said and may ask a natural follow-up question. In the browser and on the wallpaper NOVA keeps listening for 9 seconds after an answer (12 after a question) without "Hey NOVA", and speaking over her interrupts. On a call a pause or cough mid-sentence no longer splits the question, and goodbyes are warmer.
- **Live activity windows.** While a turn runs, small glass windows next to the orb show each step: the search query with results, the page being read, a mini terminal with the command and its output, and data cards for home, servers, weather and calendar. Tool events carry a sanitized preview of at most 2 KB; failed steps carry none.
- **Agent Skills.** NOVA reads open `SKILL.md` skills (Instellingen, Geavanceerd, Agent Skills, or "installeer owner/repo@skill"), offers their names and descriptions to the model and loads the full text only when needed. NOVA may install skills itself. Scripts inside skills never run.
- **SearXNG search.** A new `searxng` service in the stack is NOVA's own search engine (Dutch results, news category), with DuckDuckGo and Wikipedia as fallbacks. It is reachable only by NOVA's search path.
- **Gestalte v2.** The optional figure is rebuilt in WebGL: a full-screen bust of glowing contour lines with an electric-blue rim, a warm core, veins, sparks and a particle landscape. The orb stays the default.
- **Security.** Cross-site requests and unknown host names are refused (`NOVA_ALLOWED_HOSTS` for extra names); SIP identity is read from the address only, other contacts are read-only and only `NOVA_OWNER_SIP` gets full tools; non-owner turns cannot write the owner's memory or mute the autopilot; a connection test with a changed address no longer sends stored secrets; internal stack names and mapped IPv6 literals are blocked for webhook skills and panels.
- **One voice per answer.** Edge speech is retried twice; when it is down Piper speaks for two minutes instead of switching voices mid-answer.
- **Wallpaper input** needs NOVA for Windows v0.1.6.

Validation: API typecheck, lint, Prettier and the full API suite (3354), web svelte-check and tests (466), Rust tests and Windows clippy, and a local SearXNG container returning Dutch results.
