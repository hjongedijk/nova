# NOVA v0.1.84

Fixes the silent avatar mouth: speech energy was updated only by the original orb renderer, which stopped when the face was selected. The speech player now owns the shared meter, so the face and voice panel receive audio levels independently of the selected avatar. Playback completion and cancellation reset the meter; mouth opening is calibrated for typical speech levels.

The portrait retains its skin and eye textures, eyebrow and eyelash geometry, and textured hair. It uses less gloss, refined head proportions and a softer shoulder fade. A model cache version prevents browsers from reusing the previous asset. The same face/orb preference continues to apply to desktop, mobile, wallpaper and helper.

Validation includes web tests, type checks, lint, production build, expression and gaze checks, and synthetic audio playback with the original orb disabled. Mouth movement follows audio amplitude; phoneme-accurate lip sync is not implemented. On iOS, which bypasses Web Audio, animation uses a playback activity fallback.
