# NOVA v0.1.18

- De optionele lokale Piper-stem verschijnt onder **MCP en services** met de echte Docker-status en bestaande bevestiging voor herstarten.
- Een niet-geïnstalleerde stemruntime blokkeert het beheer van overige services niet. Een ontbrekende of gestopte runtime kan niet via de herstartactie worden gestart.
- De serviceknoppen gebruiken dezelfde vormgeving als de overige instellingen.

Bijwerken: behoud bestaande `.env`, gegevens en Compose-configuratie. Zet `NOVA_VERSION=0.1.18` en voer `docker compose pull nova stack-control mcp-egress && docker compose up -d nova stack-control mcp-egress` uit.

De persoonlijke stem blijft optioneel. Activeer het bestaande profiel `personal-voice` alleen op de eigen host, met de twee modelbestanden in `nova-data/piper-voices` en `NOVA_PIPER_TTS_URL=http://piper:5000/synthesize`. Modelbestanden en privéconfiguratie horen niet in de repository of releasebundel. Een serverupdate verandert de standaardstem niet.
