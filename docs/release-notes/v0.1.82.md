# NOVA v0.1.82

- Introduces a rigged holographic face for the Windows wallpaper and helper, with detailed irises, pupils, eye movement, blinking and expressions for listening, thinking and completed replies.
- Adds one synchronized **Gezicht / Originele orb** choice under **Instellingen → Windows → Helper en achtergrond**, also available in the helper. Switching stops the previous renderer; hidden faces release their GPU resources.
- Uses NOVA's existing voice and audio level. Mouth opening follows amplitude; phoneme-accurate lip sync is not implemented. The avatar and its assets are served locally by NOVA.
- Includes the daily backup fix for private Linphone bridge storage. NOVA's SQLite snapshot remains in its backup; the separately owned bridge needs its own backup.
- Windows agent **v0.1.4** remains the current native release, including the mixed-DPI wallpaper input fix for displays with different scaling. Install that agent to receive the native fix; this server release does not change the installed executable.

Validation: API helper preference and backup import tests, web tests, type checks, lint, production builds and browser checks with production writes blocked. Physical Windows input still needs verification on the user's displays.
