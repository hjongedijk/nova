# NOVA v0.1.58

Calls to and from your Linphone account now connect: the SIP trunk encrypts audio (SDES-SRTP), which Linphone requires. Before, NOVA's outgoing calls were dropped by the phone and incoming calls were refused with "488 Not Acceptable Here".

You can now send NOVA a text message from Linphone. A contact marked "Mag met NOVA praten" gets an answer from NOVA's normal chat, with read-only tools only; anything that needs a confirmation is refused with a pointer to the screen. Only plain-text messages are supported by Asterisk. Other contacts are not answered.

NOVA now understands Dutch call requests ("bel Harm en vertel het weer"): she gathers the information first and then proposes the call with the full text. When every free model has recently failed upstream, she tries the one due to recover first instead of refusing chat for minutes.

Update NOVA and its matching gateway image together using the production Compose file. The new `asterisk/` folder in `nova-compose.tar.gz` is needed only when `telephony` is in `COMPOSE_PROFILES`.
