# NOVA voor Windows v0.1.3

Met **Starten met Windows** en beheerrechten ingeschakeld maakt NOVA na één goedgekeurde verhoogde start een opstarttaak voor hetzelfde account. Volgende aanmeldingen starten via die taak zonder een nieuwe UAC-vraag. NOVA controleert het account en app-pad voordat de oude opstartvermelding verdwijnt. Er wordt geen wachtwoord opgeslagen.

Autostart uitschakelen verwijdert de eigen taak en opstartvermelding. UAC blijft ingeschakeld; beveiligde Windows-schermen blijven handmatig. De wijzigingen voor wallpaper-invoer, DPI en de helper uit v0.1.2 blijven inbegrepen. Daadwerkelijk opnieuw aanmelden en taakregistratie moeten op Windows worden bevestigd.
