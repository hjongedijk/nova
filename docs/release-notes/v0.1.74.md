# NOVA v0.1.74

Nieuw: NOVA for Windows verenigt de Windows-agent, desktophelper en levende achtergrond in één Rust/Tauri-app met één systeemvakicoon. Installeer `NOVA-Setup-0.1.74.exe` of pak `nova-windows.zip` uit. De oude PowerShell-scripts zitten niet meer in het nieuwe pakket.

De app kan bestaande instellingen importeren zonder de bronbestanden te verwijderen. Importeer eerst; schakel daarna de oude agent uit via **Oude agent vervangen**. Koppel de app met NOVA via **Instellen en koppelen** en **Instellingen → Koppelingen → Windows-agent**. Zie [de installatie- en terugkeerinstructies](https://github.com/hjongedijk/nova/blob/v0.1.74/docs/windows-agent.md).

Nieuw: controle op GitHub-updates bij opstarten en elke zes uur. Updates vereisen een expliciete klik op **Bijwerken en herstarten**. De app controleert de handtekening en versie, bewaart de instellingen en start de installer. Publicatie van Windows-bestanden vereist een geslaagde ondertekende Windows-build.

Nieuw: native schermafbeeldingen, muis- en toetsenbordbediening, een eigen zichtbare browser en een klein live-schermvenster in NOVA. Zet pc-toegang lokaal en in NOVA aan; overnames blijven bevestiging vereisen. Ctrl+Alt+Shift+K is de noodstop. De lokale instelling voor beheerrechten herstart NOVA via Windows UAC; beveiligde UAC-schermen blijven handmatig.

De oude PowerShell-bron en downloadroutes zijn verwijderd; importeren van bestaande configuratie blijft mogelijk. Invoer naar de achtergrond is nog niet beschikbaar. Installatie, native bediening, beheerrechten, migratie en bijwerken tussen twee versies moeten nog op een echte Windows-pc worden gecontroleerd. De oude v0.1.73-release blijft beschikbaar voor terugkeer.

Werk NOVA en de bijbehorende gateway-image samen bij met het productie-Compose-bestand. Bestaande servergegevens blijven behouden; deze release voert geen opslagmigratie uit.
