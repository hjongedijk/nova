# NOVA v0.1.32

Daghoogtepunten en weekoverzichten worden duurzaam herkend vóór een tweede melding of modelaanroep. Een mislukte auditwrite veroorzaakt geen herhaling. Beschadigde voortgang stopt het schema direct; geweigerde feedopslag kan opnieuw worden geprobeerd. Het begrensde afleverjournal bewaart de laatste dag- en weekontvangst ook bij veel andere meldingen. Bestaande voortgangsbestanden blijven leesbaar.

De vaste gespreksevaluatie is uitgevoerd voor drie expliciete gratis modellen:54 antwoorden uit90 geplande gevallen. Het verslag onderscheidt Gemini-quotumproblemen, mislukte Cloudflare-toolgevallen en verzonnen handelingen/doelen bij Codestral. Alleen veilige metadata en statische beoordelingen zijn gepubliceerd; productierollen blijven gelijk.

Werk de NOVA-image bij met behoud van privéconfiguratie en gegevens. De extra NOVA-ontgrendeling blijft uit achter de geconfigureerde beveiligde reverse proxy. Deze release bewijst duurzame feedacceptatie; fysieke hoorbaarheid blijft een aparte controle.
