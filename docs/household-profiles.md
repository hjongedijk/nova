# Household profiles

NOVA supports up to eight household profiles in **Instellingen → Gedrag**. Each profile stores a label, NOVA's conversational persona cues, and optional communication preferences. Selecting a profile makes it active immediately; the active profile applies across the installation.

Profiles are a shared-household convenience. They do not authenticate a person or separate chat history, long-term memory, permissions, or device-local preferences. Anyone with access to the protected settings can switch profiles. Do not store secrets or sensitive personal details in profile fields.

Settings backups include the profile list and active profile. Older version-one backups with only a single persona profile remain supported and import as one household profile.
