# Free-provider setup

Installed OmniRoute: 3.8.51. Reviewed guide branch: release/v3.8.52.

The installed free-budget catalog matches the v3.8.52 release catalog exactly. A hasFree badge or signup credit does not prove recurring, zero-cost access.

Enter credentials in OmniRoute → Providers → Add Provider. Never put credentials in chat. For each new account, report the provider ID and confirm billing is disabled or a hard free-tier limit applies. NOVA then restricts AUTO to exact verified free models and active connection IDs.

Priority additions: Groq, OpenRouter (exact :free models), Hugging Face, Kilo Gateway (current free models), and SEA-LION. The table records which providers already have native connections.

After account confirmation, record both provider IDs and the verified account connectionIds in `data/verified-free-accounts.json`. Stop OmniRoute, run `python3 scripts/configure-free-routing.py`, start OmniRoute, then run `node scripts/provider-inventory.mjs` and `node scripts/free-provider-plan.mjs`. The configuration script creates private backups. Confirmation must come from the operator, never from a hasFree label. Additional accounts under an already verified provider require separate confirmation.

`data/free-model-exclusions.json` overlays current official evidence and live failures without rewriting the shipped catalog. Cloudflare Kimi K2.6 requires paid access; five older Cloudflare models lack advertised function calling. Gemini 2.5 Flash returned 404 for this account. Native AUTO excludes these exact models; account billing confirmation cannot override their exclusions.
