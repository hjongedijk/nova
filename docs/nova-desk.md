# NOVA Desk

NOVA Desk has been incorporated into **NOVA for Windows** in `apps/windows/`. The helper, wallpaper and HTTP agent now share `nova.exe`, one tray icon and one configuration file.

See [Windows agent](windows-agent.md) for installation, pairing, migration, development and remaining Windows acceptance checks. The old `nova-desk.exe` plus PowerShell setup is a rollback path, not the new installation model.
